**Starshard Drift** — an original arena space shooter that runs entirely offline from static files. Pilot your ship through a nebula, harvest falling starshards, chain kills into combos, dodge void motes, darters and spinners, and shatter the Void Maw boss on wave 8. WASD or arrows to fly, mouse to aim, Space or click to dash, auto-fire always on. Eight waves, pickups (shards, hearts, magnet, shield), a boss bar, pause, and win / game-over screens with restart — plus synthesised WebAudio sound, no audio files.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
